# Backsies-Web

Backsies web is the website to the board game Backsies. Backsies consists of rolling dice, drawing cards, and going towards the end of the board.

## Installation

The website consists of HTML and images that could be downloaded but I don't see why you would want to...

## Usage
This repository basically is just HTML with some extra files so you would run it by opening it in a browser or hosting it online.
